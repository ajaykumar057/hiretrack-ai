# HireTrack AI

An AI-powered SaaS platform for seamless candidate tracking, resume intelligence, and networking.

## Features
- **Dashboard & Kanban**: Manage applications efficiently.
- **Resume Intelligence**: AI-powered insights for resumes.
- **Networking**: Keep track of contacts.

## Technologies Used
- Frontend: React, Tailwind CSS, Vite
- Backend: Node.js, Express, MongoDB
